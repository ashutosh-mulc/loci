# Loci: project rules

Loci is a SPECS Lens for Devpost's Learn AR with SPECS hackathon. It turns a chosen set of my AI conversations into a memory palace in my room.

## Sources of truth
- Design: devpost/design-brief.md (approved). Don't change scope without asking me.
- Data: Assets/Scripts/PalaceData.ts, generated by tools/palace-builder. After v1, regenerate it instead of hand-editing.
- Schema and limits: devpost/data-spec.md.

## How we work
- Build the Lens through CLAD and the Lens Studio MCP, with Lens Studio open.
- Use SIK and SPECS UI Kit for every interaction, so it works with the mouse in Interactive Preview and with LEAF.
- Re-run the LEAF tests after every change.
- At the end of each session, append design changes to devpost/design-notes.md, and prompts and LEAF results to devpost/build-log.md.

## Rules
- Read exports/ only when a step asks for it, and never commit it. Only the generated data file goes in git.
- No people's names in the data. No camera, recording or face features.
- The display is additive: no dark panels; use light text and glowing elements.
- At most 8 stars per topic, labels of 4 words or fewer, and only the spot I'm looking at opens.
